# הספרייה שלי

מעקב אחרי ספרים שנלקחו מהספרייה, ספרים שכבר נקראו, והמלצות לספר הבא.

המסך הראשי מראה קודם ספרים שנמצאים אצלכם, ומתחתיהם ספרים מומלצים. לייק ודיסלייק מעבירים ספר למסך «ספרים שקראתי».

ההמלצות מתחשבות בסדרה (אם אהבתם ספר מס׳ 1 יופיעו הבאים אחריו), במחבר, בשפה ובגיל. אם כל מה שקראתם הוא בעברית, יוצעו רק ספרים בעברית. אם קראתם רק ספרי ילדים ונוער, יוצעו רק כאלה.

## הרצה

```bash
npm install
npm start
```

ואז לפתוח [http://127.0.0.1:3789](http://127.0.0.1:3789)

הקטלוג נמצא ב־`data/books.csv`. הלייקים, הדיסלייקים וההשאלות נשמרים רק במחשב שלכם, בקובץ `data/state.json`.
